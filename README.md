**One-page summary:** `SUMMARY.pdf` · **Blog (PDF):** `BLOG.pdf`

## The claim (one falsifiable sentence)

> A network can store arriving associations in a fixed-size synaptic state through Hebbian writes — no gradient step and no new memory slot per token — but as associations accumulate, interference corrupts retrieval until recall fails.

The artifact lets a learner **reproduce both halves in under 60 seconds**: store one pair → perfect recall; store forty → the same probe retrieves the wrong value, while the state stays exactly 24×24 and (with λ=1) nothing was deleted. Section 6 automates this as a timed test.

## Intended learner, prerequisites, objectives

- **Learner:** a CS/DS student or practicing data scientist who knows what a matrix–vector product and a dot product are, has used Transformers, and has *not* studied fast weights or linear attention.
- **Prerequisites:** dot product, matrix multiplication, "attention" at the level of intuition. No calculus, no neuroscience background.
- **Learning objectives.** After using the artifact, the learner can:
  1. write the Hebbian update `M ← λM + vkᵀ` and the read `r = Mq` and explain each symbol;
  2. derive (or reconstruct) the closed form `Mq = Σ λ^(t−i)(kᵢ·q)vᵢ` and explain why near-orthogonal keys give near-perfect recall at low load;
  3. **predict** the effect of each variable (load, λ, overlap, d, sparsity, noise) before dragging, and explain the two failure modes — interference vs decay;
  4. state where the mechanism appears in BDH (inference-time working memory) and BDH-CQ (additive accumulation per demonstration), and distinguish it from KV-cache Transformers and from HRM/TRM-style test-time optimization;
  5. name the core misconception: with λ=1 superposition *looks like* deletion but is not — storage is intact, retrieval degrades.

## What is live / precomputed / synthetic / animated

- **Live:** all experiments, charts, matrices, probes, the 60-second test.
- **Precomputed:** none.
- **Synthetic:** the sparse binary key/value patterns (generated by a seeded LCG; the seed is a user control).
- **Animated:** none. (The hero stream writes real states on a timer; §7 and the page header say so. `prefers-reduced-motion` replaces it with a pre-run snapshot.)
- **Toy, not BDH:** the system demonstrates the *mechanism family* BDH reports. It is not a BDH/BDH-CQ model, not trained, not spiking. Labeled in-page (§4) and here.

## Reproducing the results

**The artifact itself needs no setup:** open `index.html` in any modern browser (works offline — no build, no install, no sign-in).

**Local components** (the reference implementation and honesty tests) require:
- Python 3.9+ with `numpy` (`pip install numpy`)
- Node.js 14+ (only for the JS-core harness; Python-only verification works without it)

```bash
# 1) run the reference experiments & export fixed-seed vectors
python3 reference/fast_weights.py

# 2) run the artifact's own JS core under Node (extracted from index.html)
node reference/extract_and_run_core.js

# 3) verify: 6/6 tests incl. JS == NumPy at 1e-9
python3 reference/test_fast_weights.py     # or: pytest reference/ -q

# 4) regenerate the PDFs (requires: pip install fpdf2, pillow)
python3 tools/make_pdfs.py
```

Headline reproducible numbers (seed 42, d=24, sparsity 0.2, λ=1): exact-match recall 100% through ~10 stored pairs; <50% by ~22; interference share of retrieval ~0.84 at load 28. Crossing points are seed-dependent — that is why the seed is exposed; the qualitative collapse is robust across seeds (try 1–99 in the sandbox).

## BDH / BDH-CQ integration (summary; full module in the artifact §4)

- BDH (arXiv:2509.26507): *"The working memory of BDH during inference entirely relies on synaptic plasticity with Hebbian learning using spiking neurons."* Plus reported monosemantic synapses and sparse positive activations — the toy mirrors the sparse non-negative coding. BDH is **not** an SSM in the Mamba sense; its GPU formulation is a separate ReLU-low-rank/linear-attention construction (per the problem statement).
- BDH-CQ (arXiv:2608.09888): inference-time inputs *"continuously update the model's recurrent memory"*; queries solved by latent iteration without verbalized reasoning; per the problem statement, state *"accumulates additively per demonstration"* — exactly the toy's λ=1 regime. 150M-parameter configuration: 29.5% pass@2 on public ARC-AGI-1 at ≈$0.0007/task (developer-reported preprint; external evaluators named on the companion repo; not peer-reviewed; no deployment claimed).
- Contrast: HRM/TRM adapt *weights* per task (backward passes on augmented demonstrations); BDH-CQ adapts *state* — no parameter updates at inference.

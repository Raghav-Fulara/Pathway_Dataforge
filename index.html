Synaptic plasticity is short-term memory

How a network can turn its own wiring into working memory — and precisely how that memory fails. Everything on this page is computed live in your browser. Nothing is a video.

The claim (falsifiable): a network can store recent associations in a fixed-size synaptic state through Hebbian writes — no gradient step, no new memory slot per token — but as stored associations accumulate, interference corrupts retrieval until recall fails.
Your job is to break this sentence. Section 2 lets you do exactly that.

1 · The write, up close

One association = one outer product

Store and probe pairs yourself. Present a pair: the key lights pre-synaptic units, the value lights post-synaptic units, and every active (pre, post) pair of units strengthens its synapse by +1 — Hebb's rule, “cells that fire together, wire together.” Retrieval reads the same synapses with a cue.

write:  Mt = λ·Mt−1 + v kᵀ    read:  r = Mt·q    λ = 1.00 (pure addition here)

Why retrieval works. After t writes the state is Mt = Σᵢ λt−i vᵢkᵢᵀ, so reading with cue q gives Mtq = Σᵢ λt−i (kᵢ·q) · vᵢ Retrieval is a similarity-weighted sum of all stored values. Keys are sparse and nearly orthogonal → (kᵢ·q) ≈ 0 for everything except the matching key → the right value dominates. Keep that Σ in mind: every other term is still in there. That sum is the seed of the failure you'll cause next.

The failure is the lesson. Nothing leaked or got deleted: with λ=1 every stored pair is still perfectly present in M. Retrieval fails because superposition is not storage — the read M·q returns the matching value plus the residual similarity of every other key. Capacity is finite even though the state never grows. This exact effect — “endlessly adding new associations to a memory of finite size inevitably will reach a limit” — is the capacity limit of linear-attention memories identified by Schlag, Irie & Schmidhuber (ICML 2021).
3 · One mechanism, three vocabularies

The same equation in three fields

Same live state, same numbers — three readings. Understanding all three is what lets you read BDH (a neuron–synapse model), the fast-weights literature, and the linear-attention literature as one subject.

recent co-activation strengthens a synapse:  Δwij = vi·kj;  decay λ = forgetting;  read = pattern completion

The matrix M is the wiring: Mij is the strength of synapse from pre-synaptic unit j to post-synaptic unit i. Presenting a pair potentiates the synapses between its active units; a partial cue re-activates the completed pattern. Working memory without a separate buffer — the network's own connectivity, temporarily.

current key (pre-synaptic)
current value (post-synaptic)

Sparse, non-negative patterns mirror BDH's reported activation statistics (§4): only ~5% of units active, activations positive.

slow weights θ (fixed at inference)  +  fast weights Mt = λMt−1 + v kᵀ (rewritten every step)

The network has two weight sets at two timescales. The slow weights are learned by gradient descent and frozen at inference. The fast weights M are “parameter-shaped” memory rewritten by the input stream itself — context stored in the weights, not beside them. The line of work from Schmidhuber (1992) through fast-weight programmers (Schlag et al., ICML 2021) to Titans (Behrouz et al., 2025) and test-time-training layers (Sun et al., 2024) builds exactly this: a slow net that learns good write/read rules, and a fast state that carries the context.

In this toy the write rule is hand-set (pure Hebb); in those systems it is learned. That is the single biggest gap between the toy and the frontier.

St = λSt−1 + vtktᵀ,  ot = Stqt  ⟵  linear attention as an RNN with a matrix state

Linear (kernel) attention removes softmax so the attention state can be carried forward incrementally: no re-scanning of all past tokens, and — unlike a KV cache — the state has fixed size independent of sequence length. Gated linear attention (Yang et al., 2024), RWKV-7 (Peng et al., 2025), DeltaNet and Mamba-2's SSD view are all points in this design space: what differs is the write rule (additive, gated, delta-rule, learned).

The special case that leads to BDH-CQ. The Pathway problem statement notes that BDH-CQ relates its contextual memory to “linear-attention views of contextual association, with the special case where state accumulates additively per demonstration.” Additive per-demonstration accumulation is exactly this toy with λ = 1 per demo: each demonstration leaves a rank-one trace in recurrent state; nothing is optimized at inference (§4).

Set λ = 1 in §2 and you are looking at the additive regime; lower λ trades old memory for interference resistance.

4 · Where this lives in Pathway's BDH and BDH-CQ

This topic is not adjacent to BDH — it is BDH's mechanism

The DataForge brief describes synaptic plasticity as short-term memory as “BDH's mechanism in its conceptual neuron–synapse model, where attention becomes synaptic memory through Hebbian writes.” Here is what the primary sources actually say — every quote below is from the cited paper.

“The working memory of BDH during inference entirely relies on synaptic plasticity with Hebbian learning using spiking neurons.” — Kosowski, Uznański, Chorowski, Stamirowska & Bartoszkiewicz, The Dragon Hatchling: The Missing Link between the Transformer and Models of the Brain, arXiv:2509.26507 (2025), abstract.
“We confirm empirically that specific, individual synapses strengthen connection whenever BDH hears or reasons about a specific concept while processing language inputs.”  monosemantic synapses — same paper, abstract.
“Activation vectors of BDH are sparse and positive. We demonstrate monosemanticity in BDH on language tasks.”  sparse non-negative activations — same paper, abstract. The sparse, non-negative patterns in this toy (§0–§3) mirror this design point.
“Inputs presented at inference time continuously update the model's recurrent memory; the model then solves a query through iterative computation in a high-dimensional latent space, without verbalizing its intermediate reasoning.” — Engdahl, Kosowski, Chorowski, Stamirowska, Uznański, Jiang, Phadke, Kinas & Zhong, BDH-CQ: In-Context Learning with Recurrent Latent Reasoning, arXiv:2608.09888 (2026), abstract.

It is NOT a BDH or BDH-CQ model, not trained, not spiking, d = 24 rather than millions of units, and its write rule is hand-set rather than learned. 7 · Limitations, misconceptions, credits

What this toy does not claim

  1. Not biological realism. Hebbian co-activation capture is a computational abstraction of plasticity, not a model of LTP/LTD kinetics, neuromodulation or spiking dynamics (BDH uses spiking neurons; this toy does not).
  2. Not a trained system. The write/read rules are fixed. Frontier systems (DeltaNet, Titans, TTT, BDH) learn their write rules; capacity and noise behavior differ qualitatively once the rule is optimized.
  3. Caps, stated: d ∈ [12, 64], ≤ 80 stored pairs, ≤ 99 seeds, uniform cue noise (not Gaussian). All for sub-second response; nothing else is hidden.
  4. Metric definitions: “exact match” = retrieved vector's nearest stored value is the correct one (ℓ₂); “interference share” = ‖retrieval − decayed target term‖ / ‖retrieval‖.
  5. Numbers depend on the seed. That's why the seed is a control. The qualitative collapse is robust across seeds; the exact crossing point is not.
  6. BDH evidence is developer-reported preprints (see §4 table). A benchmark is not a deployment; a company announcement is not an independent evaluation.
  7. Common misconception: “fixed state ⇒ information is deleted.” With λ=1 nothing is deleted — retrieval, not storage, degrades. Superposition ≠ lossless storage.

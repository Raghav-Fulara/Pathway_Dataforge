# License and provenance record

## Code
- **All code in this repository** (index.html incl. fw-core, reference/, tools/) was
  written for this submission. License: **MIT** — see below.
- No third-party JavaScript libraries, no CDN dependencies, no webfonts, no external
  assets of any kind are loaded by `index.html`. Charts and heatmaps are drawn with
  the browser-native Canvas API; UI is hand-written HTML/CSS.

## Text and documents
- `SUMMARY.pdf`, `BLOG.pdf`, `README.md`, `sources/`, `tools/`: written for this
  submission. Verbatim quotes from the papers listed in `citation-ledger.md` are
  short quotations used for commentary/education with attribution (fair-use style
  citation); the papers are arXiv preprints whose abstracts state arXiv's
  non-exclusive distrib ution license.

## Data
- All "data" (key/value patterns, curves) is generated deterministically in-code by a
  seeded LCG. No external datasets. Fixed-seed fixtures
  (`expected_vectors.json`, `js_vectors.json`) are generated by the included scripts.

## Weights
- None. The artifact trains no model and loads no checkpoints — all computation is
  the hand-set Hebbian update running live in the browser (see README §live). No
  BDH/BDH-CQ weights exist publicly, and none are used or reimplemented.

## Graphics
- All graphics in `index.html` (heatmaps, pattern grids, charts) are drawn at runtime
  with the browser-native Canvas API from live computed values — there are no image
  assets in the artifact, and no third-party graphics, icons, or illustrations are
  used anywhere.

## Fonts
- None embedded in the artifact (system font stack). The PDFs embed DejaVu fonts
  (free, permissive license; rendered via fpdf2).

## Third-party concepts referenced (not copied)
- TensorFlow Playground / distill.pub-style interactive-essay conventions inspired
  the layout philosophy (referenced by the problem statement's examples list); no
  code or assets were taken from any of them.
